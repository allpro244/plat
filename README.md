# plat

A commercial real estate simulation with a procedurally generated city,
rendered at the highest fidelity achievable without an art team.

Successor to `broadway-and-wall`, which has the economy and needs the city.

- **`BRIEF.md`** — what this is, what was decided before any code existed, and
  the definition of the first milestone. Read this first.
- **`CLAUDE.md`** — the working rules. Read this second, and follow it.

Nothing is built yet. The first milestone is one seeded city block, roughly
forty procedurally generated buildings, real sun, CC0 materials, an orbital
camera locked to defined height bands, and a screenshot produced by the build
rather than by hand.
